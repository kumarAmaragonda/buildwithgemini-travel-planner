# My agent: travel-planner
One-liner: A conversational agent that helps travelers assemble personalized itineraries and illustrates each destination with custom concept visuals.

Tool coverage:
- Memory: User travel style, budget preferences, dietary restrictions, past visited cities, and home timezone
- Tools: Destination lookup, weather forecast, itinerary builder, local attraction search
- Catalog/UI: Daily itinerary cards, attraction preview cards, packing checklist tables (rendered via A2UI)
- Image gen: Postcard-style illustrations and scenic concept art for destinations and daily highlights
- Sandbox: Budget currency conversion and daily expense breakdown calculations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for budget calculations, Google Maps / Places API lookup, Cloud Trace
